# Week 2 — Linear Regression: Medical Insurance Cost Prediction

Trained a linear regression model to predict insurance charges from
age, sex, bmi, children, smoker status, and region.

Dataset: Medical Insurance Cost dataset (1338 rows, real-world data)

## Results
- MAE: $4,177
- RMSE: $5,956
- R²: 0.807

## Key finding
Smoking status is by far the biggest driver of insurance cost
(+$23,077 on average), far outweighing every other factor.
